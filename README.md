# Hydro Science and Engineering

Coursework and project work from my M.Sc. Hydro Science and Engineering at TU Dresden (since October 2025). It combines water engineering with data analysis, modelling and laboratory work, building on my B.Sc. in Geophysical Engineering ([see my Geophysics repository](https://github.com/fashliadli/Geophysics)).

## Featured project (separate repository)

| Project | What it is |
|---|---|
| [**Sedimentation basin: tracer experiments and CFD**](https://github.com/fashliadli/cfd-sedimentation-basin-ansys-fluent) | Study project with a co-author. A laboratory basin with and without a baffle, tracer videos analysed in FIJI, and a 3D CFD model in ANSYS Fluent. The README says which parts I did |

## Skills shown across the projects

- **Modelling:** 3D CFD, mesh independence, residence time distribution.
- **Statistics:** model assumptions, validation design, regression with variable selection, multiple testing.
- **Laboratory and measurement:** tracer experiments with image analysis, titration and water chemistry calculations.
- **Reporting:** stating which results are mine, which are shared, and what the limits are.

## About this repository

Each folder has a README with the method, the results and the limitations. Group work is marked as such. Raw data from courses are not included.
